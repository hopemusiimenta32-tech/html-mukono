# html-mukono

## My Mukono Guide

A responsive website about places and everyday services in Mukono, Uganda.

## Responsive Changes

- Used a mobile-first layout.
- Used Flexbox for the cards.
- Added a media query for wider screens.
- Made images responsive so they do not overflow.
- Added visible keyboard focus for accessibility.
- Made the navigation wrap on small screens.

## Testing

I tested the website at:
- 390px mobile width
- 1366px desktop width

### Problem Found and Corrected

The navigation was overflowing on a small screen. I fixed it by allowing the navigation items to wrap and adjusting the spacing.
